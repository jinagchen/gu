## 4 阶段二验证顺序

阶段二只验证环境和可行性，不提前开始完整引擎开发：

1. 使用本机 Windows 编辑、构建和评测；已有基础工具链和小文件 I/O 探针结果，继续验证依赖、数据卷及内存计量。
2. 记录目标机能力，不安装或替换无必要的系统组件。
3. 选定并固定一个可改造的磁盘图检索依赖，验证小数据构建和查询。
4. 验证同步读取与异步 I/O 最小示例，确认失败时的替代路径。
5. 输出环境报告、依赖清单、读取路径说明和内存粗算。

阶段二工程可行性与阶段三设计冻结已完成，真实静态 Engine 与读路径对照已跑通。目前处于阶段六的 WAL 底层到 Engine 联调交接，见[项目状态](project-status.md)。工程进展不关闭任何官方未决问题。
