## 盘点时的执行顺序

1. 先处理 `S7-01`、`S7-02`。将已有复现纳入自动回归，再修复发布恢复和满段停滞。
2. 接着处理跨代次回收、维护预算和写入故障。修复须覆盖已确认数据、最新版本、旧视图及重启续写。
3. 接通真实动态评测和后台读配额。先用小矩阵验证真实读写交叠与跨合并正确性，再做规模、内存、背压和尾延迟对照。
4. 用验收工件更新文档。官方规则、队伍回执及实物故障试验按各自条件登记证据。

测试前使用 ASCII 运行和临时目录，配置时通过 `AGENT_IO_BOOST_INCLUDE` 和 `AGENT_IO_TEST_PYTHON` 指向锁定依赖。以下命令从该构建配置复跑全量及 IOCP 小矩阵。

```powershell
cmake --build build/windows --config Release
```
